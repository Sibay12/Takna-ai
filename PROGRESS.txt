CHANGES IN v0.2.0
 - Gemini provider via official REST API (key in header only), error mapping (auth, rate limit, timeout, unsupported model, blocked, network).
 - POST /ai/chat stores user+assistant messages (own 7-day expiry each); POST /ai/code is not stored.
 - Concurrency-safe daily quota (ai_ai_usage, unique owner+day index); failed AI calls are refunded.
 - New env (optional): GEMINI_MODEL (default gemini-flash-latest), AI_DAILY_REQUESTS (30), AI_MAX_OUTPUT_TOKENS (2048).
 - Gemini 2.5 models were shut down 16 Oct 2026; if the default alias fails, open /admin/gemini to see usable models and set GEMINI_MODEL.
 - New tests: gemini, usage, AI routes (still not executed).

CHANGES IN v0.2.1
 - Voice-only mode support: POST /ai/chat accepts mode="voice" (short, plain, speakable replies, capped output).
 - Voice-only screen itself (orb + mic only, spoken replies, text box hidden) is an Android task: planned in Phase 2/6.
   Rules: mic only when user taps; no silent recording; stop-speaking button always available.

CHANGES IN v0.2.2
 - Auto-ping keep-alive: server pings its own /health every 10 min on Render (production only, auto-uses RENDER_EXTERNAL_URL, KEEP_ALIVE=false disables).
   Owner request; overrides the original spec rule. Caveat: Render Free = 750 hrs/month shared across ALL free web services.
 - Data is not lost when Render sleeps: it lives in MongoDB Atlas. (Atlas free M0 has no automatic backups; export manually if needed.)
 - Accessibility features (search inside other apps, screen reading) approved as an optional later Android phase.
